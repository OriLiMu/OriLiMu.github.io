# 想问问acmer们学算法的动力是什么？

如果大家经常用codeforces或者topcoder这类竞赛平台的话，可能会经常看到一个id，"Petr"Petr Mitrichev，拿到了包括IOI的金牌（2000 年、2002 年）和银牌（2001 年）、作为莫斯科国立大学团队的一员在ACM ICPC世界总决赛中获得金牌（2003 年、2005 年）。

Google Code Jam冠军（2006年），Topcoder公开赛冠军（2018，2015，2013，2006 ），Topcoder大学挑战赛冠军（2006，2007），Facebook黑客杯冠军（2011，2013 年、2017 年）以及众多全国和在线比赛。

上面的信息来自这里根据这篇文章里的信息，Petr现在应该快接近40岁了吧，但是你在codeforces上还是会看到他依然很活跃，参加比赛，分享题解，写博客等等。

我觉得他身上有两点让我觉得非常不可思议。

第一点就是年龄，对于编程竞赛领域来说，他这个年龄应该算是"高龄选手"了吧，能在他这个年纪依然保持这么强的战力实属不易啊，可以看看他在codeforces上的排名，我记得好像是黑红名！

！

第二点是看他过往的经历，已经拿过很多奖了，要说也可以功成身退了吧，至少不需要再通过名次获奖啥的来证明自己了。

但是在他的字典里似乎没有"退役"二字，唯有热爱！！
